# CRUD de Productos

Aplicación CRUD desarrollada con Spring Boot, Spring Data JPA, H2 Database y HTML, CSS, JavaScript y Bootstrap.

## Características

- Crear productos.
- Listar productos.
- Editar productos.
- Eliminar productos.
- Validación de datos.
- Selección de categoría mediante un menú desplegable.

## Tecnologías utilizadas

- Java 17
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Instalación

1. Clonar el repositorio.

```bash
git clone https://github.com/diana-sys1876/proyecto-Practica.git
```

2. Entrar al proyecto.

```bash
cd proyecto-Practica
```

3. Ejecutar la aplicación.

```bash
mvn spring-boot:run
```

4. Abrir el navegador.

```
http://localhost:8080
```

## Ejemplo de uso

Puede registrar productos como:

- Queso Campesino
- Mouse Inalámbrico
- Balón de Fútbol
